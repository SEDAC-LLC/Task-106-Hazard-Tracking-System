# Task-106-Hazard-Tracking-System
Task 106 - Hazard Tracking System (HTS). Per MIL-STD 882E, the HTS is a closed-loop database tracking all identified hazards from all analysis tasks throughout the system life-cycle. This tool provides: master HTS register with all minimum data elements (MDEs), HTS completeness scoring, RAC trend analysis, closure velocity metrics, and gap analysis
